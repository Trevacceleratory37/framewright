## 🎬 What Is framewright?

framewright is a friendly tool that turns plain text code into short videos. You don't need expensive video software or editing skills. If you can type a few lines of simple instructions, framewright handles the rest.

Think of it like baking with a recipe. You give framewright the ingredients (your code) and it bakes a complete video for you. Every single picture in your video is created from scratch using math and logic. No cameras, no actors, no complicated timelines.

The magic is simple: each frame of your video is just a formula. Give it a frame number, a random seed, and a width value, and it produces a perfect image. String thousands of those together, and you have a smooth, beautiful video.
